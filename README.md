# Arena

Bots play slime volleyball, the winners have offspring, and a public page
shows a map that fills with playing styles, the champion's family tree and
replays anyone can watch or play. Built to learn optimisation by doing.

Read, in order: `PLAN.md` (who builds what and in what order),
`docs/CONVENTIONS.md`, `docs/ABI.md` (the kernel), `docs/DATA.md` (trainer
to page). `PREFLIGHT.md` holds the idea synthesis and the machine checks of
26 October 2026.
